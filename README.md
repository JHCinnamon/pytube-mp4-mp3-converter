# pytube-mp4-mp3-converter
Only works on PytubeFix versions not PyTube YT alrogirthm changes often

This App reads the chunks from the youtube stream and rebuilds them as an MP4, then using movietube and ffmpeg compiles the mp4's audio stream into .mp4 or wav file

Not all files chunk successfully
